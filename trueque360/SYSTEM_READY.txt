🎯 FLUJO DE USO:
┌────────────────────────────────────────────────────────────────────────────────┐
│  1. Usuario A ve artículo de Usuario B                                        │
│  2. Hace clic en "💬 Contactar al Vendedor"                                   │
│  3. Se abre modal ChatInitiator con mensaje predeterminado                    │
│  4. Usuario A puede editar o mantener el mensaje                              │
│  5. Hace clic en "Enviar Mensaje"                                             │
│  6. Sistema crea Conversation + Message en BD                                 │
│  7. Usuario A va a "✉️ Mensajes" en el sidebar                                │
│  8. Ve la conversación con Usuario B                                          │
│  9. Puede ver el historial y enviar más mensajes                              │
│  10. Usuario B recibe y puede responder                                       │
└────────────────────────────────────────────────────────────────────────────────┘
